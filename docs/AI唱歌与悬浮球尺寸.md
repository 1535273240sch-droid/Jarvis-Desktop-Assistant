# AI 唱歌 & 悬浮球尺寸（v1.4.0）

> 本文档说明 v1.4.0 新增的两项能力：让 Jarvis **生成歌曲并播放**，以及**悬浮球尺寸可调 / 随状态自适应**。

## 一、AI 唱歌

### 它是什么

用户对 Jarvis 说「唱首歌」「想听歌」「给我来一首 XX 风格的歌」，Jarvis 会调用阶跃星辰（StepFun）的音乐生成模型，**现场创作一首带人声的完整歌曲**，生成完成后自动在本机播放，音频同时落盘保存。

支持三种模式（模型能力，当前默认只用第一种）：

| 模式 | 说明 |
| :--- | :--- |
| 文本生成歌曲 | 风格描述 +（可选）歌词 → 带人声的完整歌曲；不填歌词时由模型自动写词 |
| 纯器乐 | 只给风格描述，`instrumental=true`，无人声 |
| 翻唱 / 干声配乐 | 提供参考歌或清唱干声再编曲（接口已具备，界面暂未开放） |

### 工作流程（重要：异步，不阻塞对话）

```
用户说「唱首歌」
  → 模型调用内置工具 sing_song（把用户的话转写成风格描述 caption）
  → 主进程立即回执「已开始创作」，模型马上回话安抚用户
  → 后台提交生成任务并每 5 秒轮询（进度以 🎵 系统消息播报）
  → 生成完成：自动播放 + 通知「歌曲已生成并开始播放」
```

**为什么是异步**：生成一首歌需要 1~3 分钟。若让语音链路同步等待工具结果，用户会经历长时间沉默，且服务端可能判定工具调用超时。改为「立即回执 + 后台生成」后，用户全程都有反馈。

### 配置项

| 配置 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `musicEnabled` | `true` | 面板「设置 → AI 唱歌」开关；关闭后模型会提示用户去开启 |
| `musicModel` | `stepaudio-3-music-preview` | 音乐模型 ID。**preview 版有下线风险**，模型不可用时可改这里 |
| `musicBaseUrl` | `https://api.stepfun.com` | 音乐接口地址 |
| `musicApiKey` | 空 | 音乐专用 Key；为空则沿用主 `apiKey`。**下发给渲染层时会脱敏** |

生成音频保存位置：`%APPDATA%\jarvis-desktop-assistant\music\jarvis-song-<时间戳>.mp3`

### 使用与成本提醒

- 直接说「给我唱一首轻快的歌」「来首适合下雨天听的」「用这个歌词唱：……」即可。
- 生成按次计费（走你的 StepFun 账号额度）。余额不足时接口返回 402，Jarvis 会明确告知「余额不足」而不是假装成功。
- 内容审核拦截会返回 `censor`，此时 Jarvis 会提示换个主题。

### 已知限制

1. **音乐与 AI 语音共用同一播放通道**：播歌期间若 Jarvis 说话，两者会混音（未做自动压低音乐的处理）。
2. **时长不可控**：输出时长由模型决定，通常 1~3 分钟，无法用参数精确指定。
3. **打断即停止**：用户打断、结束会话或退出应用时，正在播放的歌会停止。

## 二、悬浮球尺寸可调 / 自适应

### 手动调节

面板「设置 → 悬浮球尺寸」拖动滑块（80~400 px，默认 260）：

- **实时生效**：拖动即改窗口尺寸，球体渲染自动跟随；
- **保持球心**：缩放以球心为基准，不会「跑偏」；
- **自动持久化**：尺寸与位置都会保存，重启后保持。

窗口本身仍是 `resizable:false`，尺寸只由代码设置，不会出现用户误拖边框把球拉变形的情况。

**升级兼容**：如果你在此前版本里已经有自己的球体尺寸（存在窗口状态里），升级后**以该尺寸为基准**，不会被默认值 260 突然缩小；只有当你从未设置过、且配置里没有 `orbSize` 时才会用默认值。首次用滑块调整后，尺寸会写进配置并长期生效。

### 随状态自适应

打开「随状态自适应」后，悬浮球会按助手状态轻微缩放：

| 状态 | 倍率 |
| :--- | :--- |
| 播报（speaking） | ×1.12 |
| 聆听（listening） | ×1.06 |
| 其他 | ×1.0 |

- 缩放**在基准尺寸上乘倍率**，永不改写手动设定的基准值；关闭开关立即恢复基准。
- 过渡采用 6 步 ×18ms 的分步动画：窗口尺寸变化会让 WebGPU 渲染目标重建，步数过多会卡顿，故做了刻意限制。

### 一个容易踩的坑（已修）

悬浮球的点击/拖动命中区域原先写死为半径 110px（对应 260px 窗口）。窗口放大后如果不同步调整，就会出现「看得见球但点不到」或「球外空白处也能点到」。现已改为按窗口尺寸推导（比例 0.42，260px 时仍为 ~110px，向后兼容）。
