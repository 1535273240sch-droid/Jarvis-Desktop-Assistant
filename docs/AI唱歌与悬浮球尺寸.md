# AI 唱歌与悬浮球尺寸

> 本文档说明两项能力：让 Jarvis **生成歌曲并播放**，以及**悬浮球尺寸可调 / 随状态自适应**。
> 悬浮球的渲染、多主题与稳定性见 `docs/悬浮球-WebGPU-稳定性.md`；桌面能力与授权见 `docs/使用说明.md`。

## 一、AI 唱歌（生成音乐）

### 它是什么

用户说「唱首歌」「想听歌」「给我来一首 XX 风格的歌」，Jarvis 会调用阶跃星辰（StepFun）的音乐生成模型，
现场创作一首**带人声的完整歌曲**，生成完成后自动在本机播放，音频同时落盘保存。

- **已实现**：文本生成歌曲 —— 把用户的话转写成风格描述（caption）后提交生成。
- **未实现：自唱**（把自己的声音唱出来，即歌声转换 SVC，Singing Voice Conversion）—— **没有任何代码路径**，界面也未开放。

### 面板配置项（设置 → AI 唱歌）

| 配置项 | 字段 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| AI 唱歌开关 | `musicEnabled` | `true` | 关闭后模型会提示用户去开启 |
| 音乐接口地址 | `musicBaseUrl` | `https://api.stepfun.com` | 只填**根地址**（见下） |
| 音乐模型 ID | `musicModel` | `stepaudio-3-music-preview` | preview 版有下线风险，404 时在此更换 |
| 音乐专属 API Key | `musicApiKey` | 空 | 留空沿用主 `apiKey`；下发给渲染层时**脱敏** |

**接口地址只填根地址即可**：程序会自动拼接 `/v1/audio/music/submit`，并自动去掉地址结尾的 `/v1`。
即使填成 `https://api.stepfun.com/v1`，也不会拼出 `/v1/v1/...` 而 404。

### 工作流程（异步，不阻塞对话）

```
用户说「唱首歌」
  → 模型调用内置工具 sing_song（把用户的话转写成风格描述 caption）
  → 主进程立即回执「已开始创作」，模型马上回话安抚用户
  → 后台提交生成任务并每 5 秒轮询（进度以 🎵 系统消息播报）
  → 生成完成：自动播放 + 通知「歌曲已生成并开始播放」
```

异步原因：生成一首歌约 1~3 分钟；若让语音链路同步等待工具结果，用户会长时间沉默，且可能触发服务端工具调用超时。
改为「立即回执 + 后台生成」后，用户全程都有反馈。

生成音频落盘：`%APPDATA%\jarvis-desktop-assistant\music\jarvis-song-<时间戳>.mp3`

### 失败如实告知

| 返回 | 含义 | 处理 |
| :--- | :--- | :--- |
| 401 | API Key 无效 | 明确告知，不假装成功 |
| 402 | 余额不足 | 告知走 StepFun 账号额度 |
| 404 | 模型不可用 | 提示在设置里更换模型 ID |
| 429 | 请求过于频繁 | 提示稍后重试 |
| censor | 内容审核拦截 | 提示换个主题 |
| 超时（约 6 分钟） | 生成未完成 | 告知超时 |

- 同一时刻只允许一首（单飞，避免重复扣费）。

### 已知限制

1. **音乐与 AI 语音共用同一播放通道**：播歌期间若 Jarvis 说话，两者会混音（未做自动压低音乐）。
2. **时长不可控**：输出时长由模型决定，通常 1~3 分钟，无法用参数精确指定。
3. **打断即停止**：用户打断、结束会话或退出应用时，正在播放的歌会停止。

## 二、悬浮球尺寸

### 手动调节

面板「设置 → 悬浮球尺寸」拖动滑块（**80~400 px**，默认 260）：

- **实时生效**：拖动即改窗口尺寸，球体渲染自动跟随；
- **保持球心**：缩放以球心为基准，不会跑偏；
- **自动持久化**：尺寸与位置都会保存，重启后保持。

窗口仍是 `resizable:false`，尺寸只由代码设置。命中区域按窗口尺寸推导（比例 0.42，260 px 时约 110 px），
避免窗口放大后出现「看得见球却点不到」或「球外空白也能点到」。

### 随状态自适应

打开「随状态自适应」后，悬浮球按助手状态轻微缩放：

| 状态 | 倍率 |
| :--- | :--- |
| 播报（speaking） | ×1.12 |
| 聆听（listening） | ×1.06 |
| 其他 | ×1.0 |

- 缩放**只在手动基准上乘倍率**，永不改写手动设定的基准值；关闭开关立即恢复基准。
- 过渡采用 6 步 ×18 ms 分步动画：窗口尺寸变化会重建 WebGPU 渲染目标，步数过多会卡顿，故刻意限制。

## 三、相关模块

| 文件 | 职责 |
| :--- | :--- |
| `src/main/music.ts` | 音乐生成：提交 / 轮询 / 落盘 / 单飞 / 错误中文化 / 接口地址归一化 |
| `src/main/orb-size.ts` | 球体尺寸：手动基准 + 自适应倍率 + 分步动画 + 持久化 |
| `src/main/orchestrator.ts` | 内置工具 `sing_song`（异步生成 + 播放 + 进度播报） |
| `src/main/config.ts` | 音乐与球体尺寸配置项、`clampOrbSize()`、`musicApiKey` 脱敏 |
| `src/renderer/panel.html` | 音乐开关与三项音乐配置、尺寸滑块与自适应开关、音乐播放（WebAudio 频谱驱动球体） |
