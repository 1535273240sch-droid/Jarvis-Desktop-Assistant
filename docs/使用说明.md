# 使用说明

> 面向使用者。安装与首次配置见 [安装说明.md](安装说明.md)；悬浮球稳定性细节见 [悬浮球-WebGPU-稳定性.md](悬浮球-WebGPU-稳定性.md)。

## 一、启动与界面

启动后有两个窗口：

- **悬浮球**：桌面右下角的液态玻璃球，透明、置顶、可拖动。
- **对话面板**：聊天记录、输入框、控制按钮与设置区。

托盘图标右键有快捷菜单（切换状态、启动/停止会话、打断、看屏幕、WebGPU 自检、打开日志等）。

## 二、悬浮球怎么用

| 操作 | 方法 |
|---|---|
| 拖拽 | 按住球体拖动，松手后记忆位置 |
| 点击穿透 | 球体以外区域自动穿透，不影响你操作其它程序 |
| 调尺寸 | 面板滑块 80~400px，保持球心并自动持久化 |
| 随状态自适应 | 开启后播报 ×1.12、聆听 ×1.06（只在手动基准上乘倍率），关闭即恢复 |
| 切换主题 | 默认 **siri**，可导入 5 套主题（霜白/蛋白石/深海蓝/紫晶/粒子丝带）；切换会热重载球体页，**所有主题说话动态一致** |

球体会**同时**对麦克风输入（你在说）与扬声器输出（助手在说）产生起伏，静音时回落。

## 三、语音对话

1. 点 **「启动语音会话」**，首次允许麦克风权限。
2. 直接说话，停一下模型自动接话（Server VAD 自动断句）。
3. 想插话**直接开口**即可打断，也可点面板「打断」或托盘「打断当前播报」。

文字输入框 **Enter 发送**（Shift+Enter 换行），与语音共用同一会话上下文。

## 四、怎么让它看屏幕

点 **「看屏幕」**，或说「帮我看看这个报错」「屏幕上是什么」。助手会截取**当前活动窗口**交给视觉模型分析，截图以缩略图显示在对话里。

> 技术说明：需 `screen-capture` 授权（**现已默认开启**）。实时语音通道不传图，视觉走独立 HTTPS 通道，所以比语音回复慢 1~3 秒。

## 五、怎么让它唱歌

1. 确认面板「设置 → AI 唱歌」已开启（**默认开启**）。
2. 说「唱首歌」「来首适合下雨天听的歌」。
3. 助手立即回执，后台异步生成（每 5 秒播报进度），完成后自动播放并通知。

设置区可配三个音乐选项：**音乐接口地址**（默认 `https://api.stepfun.com`）、**音乐模型 ID**（默认 `stepaudio-3-music-preview`）、**音乐专属 API Key**（留空沿用主 Key）。

> 接口地址只填**根地址**即可，程序自动拼 `/v1/audio/music/submit`；结尾的 `/v1` 会被自动去掉。失败会如实告知（401 Key 无效 / 402 余额不足 / 404 模型不可用 / 429 频繁 / 内容审核 / 超时约 6 分钟）。同一时刻只允许一首；音乐与语音共用播放通道，同时说话会混音。

## 六、长任务与急停

- 长任务（浏览器搜索整理、指挥编码 Agent、微信草稿）进度在面板**独立展示**，不受语音六态看门狗影响。
- 急停 **`Ctrl+Alt+X`**（面板与托盘也有「停止所有桌面任务」）：取消任务队列、阻断内外部 MCP 调用、中断播报。
- 退出后未完成任务持久化为「已暂停」，重启由你决定继续或取消，不自动重放副作用。

## 七、设置项

| 设置 | 作用 |
|---|---|
| StepFun API Key | 语音与视觉凭证，只存本机、不写日志 |
| 实时模型 ID | 默认 `stepaudio-3-realtime-preview`（预览版，限免结束后会下线，失效可改 `stepaudio-2.5-realtime` 或 `step-1o-audio`） |
| 屏幕理解模型 ID | 默认 `step-5-preview` |
| 工具执行白名单目录 | 每行一个绝对路径；留空 = 禁用工具执行 |
| AI 唱歌 | 音乐接口地址 / 模型 ID / 专属 API Key（见第五节） |
| 执行模式 | 全自动（默认，直接执行仅记审计）/ 逐次确认（高危操作弹窗） |
| 能力授权 | 屏幕录制 / 鼠标 / 键盘 / 对外发送分项；桌面三类默认开启，对外发送永不默认授予 |
| WebGPU 自检 | 检查显卡是否支持球体渲染 |

## 八、配置与日志位置

| 内容 | 路径（`%APPDATA%\jarvis-desktop-assistant\`） |
|---|---|
| 配置（含 API Key） | `config.json` |
| 授权 | `authorization.json` / `authorization-revoked.json` |
| 审计 | `logs\audit.jsonl` |
| 日志 | `logs\jarvis-orb.log`、分类错误 `logs\errors.jsonl` |
| 音乐 | `music\*.mp3` |

## 九、出问题自查

| 现象 | 排查 |
|---|---|
| 工具调用提示未授权 | 面板「设置 → 能力授权」检查对应能力是否被撤回；撤回需显式重新授权 |
| 提示 WebGPU 不可用 | 更新显卡驱动；托盘「WebGPU 自检」看原因 |
| 球体黑屏 / 消失 | 看设置区「球体恢复状态」，点 **「重试恢复球体」** 立即重载；仍不行看 `logs\jarvis-orb.log` |
| 看屏幕很慢 | 视觉走独立通道，正常慢 1~3 秒 |
| 语音约半小时断一下 | 官方 30 分钟上限，应用在 28 分钟自动重建并迁移上下文 |

## 十、安全须知

1. API Key 只在主进程使用，界面拿不到明文。
2. 对外发送 / 账号支付类动作**逐次独立确认**，全自动模式不豁免。
3. 目录白名单**不约束终端命令**，是减少误操作而非沙箱；建议给 AI 单独开一个工作目录。
4. 不建议让 AI 代填密码。
