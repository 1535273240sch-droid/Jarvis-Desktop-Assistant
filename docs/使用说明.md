# 使用说明

## 一、界面概览

启动后有两个窗口：

- **悬浮球**：桌面右下角的液态玻璃球。透明、置顶、可拖动（按住球体拖）。
  - 球体以外区域鼠标可穿透，不影响你操作其它程序。
  - 右键托盘图标可打开菜单（切换状态、启动/停止会话、打断、看屏幕、WebGPU 自检、打开日志等）。
- **对话面板**：聊天记录、输入框、控制按钮、设置区。

## 二、基本用法

### 语音对话

1. 点 **「启动语音会话」**。
2. 直接说话，说完了停一下，模型会自动接话（服务端 VAD 自动断句）。
3. 想插话时**直接开口说话**即可打断 —— 助手会立即闭嘴、清空未播完的音频，并开始听你说。

### 文本输入

在输入框打字，**Enter 发送**（Shift+Enter 换行）。文字和语音共用同一个会话上下文。

### 打断

三种方式：
- 直接开口说话（最自然）
- 点面板的 **「打断」** 按钮
- 托盘菜单 →「打断当前播报」

打断会依次执行：清空本地播放缓冲 → 取消服务端生成 → 清空服务端输入缓冲。所以**不会**出现"已经打断了还在念"的情况。

### 看屏幕

点 **「看屏幕」**，或直接说：
- "帮我看看这个报错"
- "屏幕上是什么"
- "当前窗口在显示什么"

助手会截取**当前活动窗口**，交给视觉模型分析，然后告诉你结果。截图会以缩略图形式显示在对话里。

> 技术说明：因为实时语音通道**不支持图像**（官方限制模态为文本+音频），这条"看屏幕"走的是**独立的 HTTP 视觉通道**，所以比普通语音回复慢 1–3 秒。

## 三、工具执行（控制电脑）

启用前提：已在设置里配置目录白名单（见安装说明）。

### 支持的指令示例

| 能力 | 示例说法 | 实际动作 |
|---|---|---|
| 打开软件 | "打开记事本" / "打开计算器" | 启动对应程序 |
| 打开网页 | "打开百度" / "打开 github.com" | 调起浏览器访问 |
| 文件管理 | "在文档目录建一个 test 文件夹" / "看看 D 盘有哪些文件" | 创建目录、列目录、读文件 |
| 终端执行 | "运行一下 ipconfig 看看网络" | 执行命令并读回输出 |
| 代码生成 | "帮我写一个 Python 冒泡排序保存到 a.py" | 写文件 |
| 项目创建 | "建一个 vite 项目" | 建目录结构 + 执行初始化命令 |
| 桌面控制 | "帮我点击登录按钮" / "帮我关闭当前窗口" | 截图定位 → 确认 → 点击 / 发送 alt+f4 |
| 键盘输入 | "帮我输入 hello world" | 向前台窗口输入文字 |

### 高风险操作确认

下列操作会**弹出确认框**，展示完整命令与影响，你点"允许"才会执行：

- 递归删除、格式化、磁盘分区、关机重启
- 结束进程、删除注册表项
- 管道下载执行（远程代码执行）
- 所有文件写入/移动、终端命令启动、修改 DesktopCommander 自身配置

**60 秒内不响应视为拒绝**。所有决定都写入审计日志。

## 四、六种状态

| 状态 | 什么时候出现 | 球体观感 |
|---|---|---|
| **空闲** | 待命中 | 冷调静态 |
| **聆听中** | 检测到你开始说话 | 青绿流动，随你的声音起伏 |
| **思考中** | 模型正在推理 | 白紫湍流 |
| **执行中** | 正在调用工具 | 琥珀金 |
| **播报中** | 正在播放语音回复 | 亮青脉动，随声音起伏 |
| **错误** | 网络/鉴权/工具失败 | 暗红警示 |

球体会**同时**对麦克风输入（你在说）和扬声器输出（助手在说）产生起伏，静音时回落。

## 五、设置项说明

| 设置 | 作用 |
|---|---|
| **StepFun API Key** | 语音与视觉功能的凭证。保存在本机，不写日志 |
| **实时模型 ID** | 默认 `stepaudio-3-realtime-preview`。这是限免预览版，官方说明**限免结束后会下线**。如失效请改为 `stepaudio-2.5-realtime` 或 `step-1o-audio` |
| **屏幕理解模型 ID** | 默认 `step-5-preview` |
| **工具执行白名单目录** | 每行一个绝对路径。留空 = 禁用工具执行 |
| **WebGPU 自检** | 检查显卡是否支持球体渲染 |

## 六、安全须知

1. **API Key 只在本机**：所有联网请求都在主进程发出，界面永远拿不到明文 Key。
2. **确认框不是障碍而是保护**：每次点击/输入都要你点头，避免 AI 误操作。
3. **目录白名单不等于沙箱**：DesktopCommander 的白名单**不约束终端命令**，理论上可通过终端访问白名单外的路径。应用层已对已知危险命令做了拦截，但这仍是**减少误操作**而非隔离。
4. **审计日志**：`%APPDATA%\jarvis-desktop-assistant\logs\audit.jsonl`，记录每次工具调用（含被拒的）、点击、输入、配置变更。
5. **建议**：不要把白名单设为 `C:\` 或用户主目录整体；给 AI 单独开一个工作目录更安全。

## 七、已知限制（如实列出）

1. **语音会话单次最长 30 分钟**（官方硬限制）。应用会在 28 分钟自动重建会话并迁移上下文，正常情况下你察觉不到。
2. **实时语音通道不支持图像**，屏幕理解走独立通道，有额外延迟。
3. **模型可能下线**：默认用的是预览版，官方声明限免结束后下线，故模型 ID 做成了可配置项。
4. **球体硬依赖 WebGPU**，显卡不支持时无法显示，且无软件降级方案。
5. **桌面控制的坐标依赖视觉模型输出**，若模型给出的坐标不准，可能点错位置 —— 所以每次都有人工确认。高 DPI 与多显示器下建议先"看屏幕"确认目标位置。
6. **首次使用建议在测试目录里试用工具执行**，确认行为符合预期后再放开到正式目录。
7. **密码类输入**：不建议让 AI 代填密码，请手动输入。
