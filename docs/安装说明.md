# 安装说明

## 一、系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位）。任务书目标平台为 Windows 11 |
| 显卡 | **必须支持 WebGPU**（DirectX 12 及以上）。球体硬依赖 WebGPU，无软件降级 |
| 内存 | 建议 8 GB 以上 |
| 磁盘 | 安装约 400 MB |
| 网络 | 需要访问 `api.stepfun.com`（语音与视觉功能） |
| 音频 | 麦克风 + 扬声器（语音对话需要） |

## 二、安装步骤

1. 双击 `Jarvis-Setup-1.0.0-x64.exe`。
2. **若出现 Windows SmartScreen 警告**（"Windows 已保护你的电脑"）：
   - 本安装包未做代码签名，这是预期现象。
   - 点击 **"更多信息" → "仍要运行"** 即可继续。
3. 选择安装目录（默认在用户目录下，无需管理员权限），点"安装"。
4. 安装完成后桌面与开始菜单会生成 **Jarvis** 快捷方式。

## 三、首次启动配置

### 1. 确认球体显示正常

启动后屏幕右下角应出现一个**液态玻璃球**，同时打开对话面板。

若球体没有出现，或弹出"WebGPU 硬件加速不可用"：
- 更新显卡驱动（NVIDIA / AMD / Intel 官网驱动）
- 确认系统已开启硬件加速
- 右键"此电脑" → 管理 → 设备管理器，确认显卡正常工作

### 2. 配置 API Key

1. 在面板底部展开 **「设置与状态」**。
2. 在 **StepFun API Key** 一栏填入你的 Key，点"保存"。
3. 保存后显示 `已配置：***abcd` 即成功。

> **Key 的存放位置**：`%APPDATA%\jarvis-desktop-assistant\config.json`
> 它只存本机，**不会**写入日志，也不会随代码提交。你也可以改用环境变量 `STEPFUN_API_KEY`。

### 3. 启动语音会话

1. 点 **「启动语音会话」**。
2. 首次会请求麦克风权限，选择"允许"。
3. 状态栏显示"已连接"后，直接对麦克风说话即可。

### 4. （可选）开启工具执行

工具执行默认**关闭**（因为白名单为空时不会启动）。

1. 在设置里的 **"工具执行（MCP）允许访问的目录"** 填写允许 AI 读写的目录，每行一个，例如：
   ```
   C:\Users\你的用户名\Documents
   C:\Users\你的用户名\Desktop\测试
   ```
2. 点 **"保存白名单并重启工具"**。
3. 设置里 **MCP 状态** 显示 "已就绪（12 个工具）" 即成功。

> **为什么必须填目录**：DesktopCommander 的目录白名单为空时等于放开整个文件系统。为避免这个风险，本应用在白名单为空时拒绝启动 MCP。
>
> **注意**：目录白名单 **不约束终端命令**，且可被软链接等方式绕过。它只能减少误操作，**不是沙箱**。

## 四、常见问题

| 现象 | 原因与解决 |
|---|---|
| 球体不显示，界面正常 | 显卡不支持 WebGPU 或驱动过旧。用托盘菜单「WebGPU 自检」查看具体原因 |
| 点"启动语音会话"提示缺少 API Key | 未配置 Key，见上文第三步 |
| 状态栏一直"未连接" | 检查网络能否访问 `api.stepfun.com`；确认 Key 有效且账号已开通实时语音权限 |
| 说话没有反应 | 检查麦克风权限（Windows 设置 → 隐私 → 麦克风）；确认已在设置里选了正确的默认输入设备 |
| 球体不随声音起伏 | 只有 6 个预设支持音频响应，本项目固定使用 `siri`（支持）。若球体完全不动，检查是否已启动会话 |
| 工具调用总是弹确认框 | 这是设计如此。高风险操作必须人工确认。可在设置中关闭"高风险确认"（不建议） |
| 提示"工具执行不可用" | 白名单为空或 MCP 未就绪，见上文第四步 |
| "看屏幕"很慢 | 视觉理解走独立 HTTP 通道，比语音慢 1–3 秒，属正常 |
| 语音会话约半小时后像"断了一下" | 官方 30 分钟上限。本应用在 28 分钟自动重建会话并迁移上下文，通常无感 |

## 五、日志与数据位置

| 内容 | 路径 |
|---|---|
| 配置文件（含 API Key） | `%APPDATA%\jarvis-desktop-assistant\config.json` |
| 运行日志 | `%APPDATA%\jarvis-desktop-assistant\logs\jarvis-orb.log` |
| 审计日志（工具调用/点击/输入） | `%APPDATA%\jarvis-desktop-assistant\logs\audit.jsonl` |

托盘菜单里有"打开配置文件""打开日志目录""打开审计日志"三个快捷入口。

## 六、卸载

通过「设置 → 应用」或开始菜单卸载 **Jarvis**。

若要同时清除配置与日志，手动删除 `%APPDATA%\jarvis-desktop-assistant` 目录。
