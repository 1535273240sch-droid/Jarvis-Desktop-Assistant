# 安装说明

## 一、系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位），目标平台 Windows 11 |
| 显卡 | **必须支持 WebGPU**（DirectX 12 及以上）；球体硬依赖 WebGPU，无软件降级 |
| 内存 | 建议 8 GB 以上 |
| 磁盘 | 安装约 400 MB |
| 网络 | 需访问 `api.stepfun.com`（语音与视觉）；音乐需访问所配音乐接口地址 |
| 音频 | 麦克风 + 扬声器 |

## 二、安装步骤

1. 双击 `Jarvis-Setup-<版本>-x64.exe`。
2. 若出现 Windows SmartScreen 警告（"Windows 已保护你的电脑"）：安装包未做代码签名，属预期现象，点 **"更多信息" → "仍要运行"** 继续。
3. 选择安装目录（默认在用户目录下，无需管理员权限），点"安装"。
4. 完成后桌面与开始菜单生成 **Jarvis** 快捷方式。

> **安装包不内置任何密钥**，配置一律在首次启动后填写。

## 三、首次启动配置

### 1. 确认球体显示

启动后右下角应出现液态玻璃球并打开面板。若球体不显示或提示"WebGPU 硬件加速不可用"：先更新显卡驱动，确认系统已开启硬件加速，再用托盘「WebGPU 自检」查看具体原因；也可参考 [使用说明.md](使用说明.md) 的「出问题自查」。

### 2. 配置 API Key 与音色

1. 面板底部展开 **「设置与状态」**。
2. 在 **StepFun API Key** 填入 Key，点"保存"；显示 `已配置：***abcd` 即成功。
3. 选择音色（实测可用：`cixingnansheng` 磁性男声 / `zhengpaiqingnian` 正派青年 / `wenrounvsheng` 温柔女声），保留自定义入口。

> Key 存放于 `%APPDATA%\jarvis-desktop-assistant\config.json`，只存本机、不写日志、不随代码提交。也可改用环境变量 `STEPFUN_API_KEY`。

### 3. 启动语音会话

点 **「启动语音会话」**，首次允许麦克风权限；状态栏显示"已连接"后即可说话。

### 4. （可选）工具执行、AI 唱歌与能力授权

- **工具执行**：在设置里的「工具执行（MCP）允许访问的目录」填写允许 AI 读写的目录（每行一个绝对路径），点 **"保存白名单并重启工具"**；MCP 状态显示"已就绪（12 个工具）"即成功。**白名单为空时拒绝启动 MCP**。
- **AI 唱歌**：默认开启，无需额外配置；如需独立额度，可在「设置 → AI 唱歌」单独填写音乐接口地址、模型 ID 与专属 API Key。
- **能力授权**：桌面三类能力（屏幕录制 / 鼠标 / 键盘）**默认开启**；用户主动撤回的保持停用；**对外发送永不默认授予**。

> 目录白名单**不约束终端命令**，且可被软链接绕过；它只能减少误操作，**不是沙箱**。

## 四、文件位置

| 内容 | 路径（`%APPDATA%\jarvis-desktop-assistant\`） |
|---|---|
| 配置（含 API Key） | `config.json` |
| 授权 | `authorization.json` / `authorization-revoked.json` |
| 运行日志 | `logs\jarvis-orb.log` |
| 审计日志（工具调用/点击/输入） | `audit.jsonl` |
| 分类错误 | `errors.jsonl` |
| 音乐 | `music\*.mp3` |

托盘菜单有"打开配置文件""打开日志目录""打开审计日志"快捷入口。

## 五、升级与自动更新

- **手动升级**：直接运行新版 `Jarvis-Setup-*.exe` 覆盖安装，配置与日志保留在 `%APPDATA%` 不受影响。
- **自动更新**：基于 electron-updater + GitHub Releases，**默认关闭**；在 `config.json` 中将 `autoUpdate` 置为 `true` 后启用。启用后启动约 8 秒静默检查、自动后台下载，下载完成弹窗询问是否立即重启安装。

## 六、卸载

通过「设置 → 应用」或开始菜单卸载 **Jarvis**。如需同时清除配置与日志，手动删除 `%APPDATA%\jarvis-desktop-assistant` 目录。

## 七、常见问题

| 现象 | 原因与解决 |
|---|---|
| 杀软 / 系统误报 | 安装包未做代码签名，可能被 SmartScreen 或杀软拦截；选"仍要运行"或加入信任。如需正式签名，发布方配置 `WIN_CSC_LINK` / `WIN_CSC_KEY_PASSWORD` 即可自动签名 |
| 球体不显示，界面正常 | 显卡不支持 WebGPU 或驱动过旧；用托盘「WebGPU 自检」查看原因 |
| 球体黑屏 / 消失 | 面板「球体恢复状态」→ 点「重试恢复球体」立即重载；仍不行看 `logs\jarvis-orb.log` |
| 点"启动语音会话"提示缺少 API Key | 未配置 Key，见第三节 |
| 状态栏一直"未连接" | 检查网络能否访问 `api.stepfun.com`，确认 Key 有效且已开通实时语音权限 |
| 说话没有反应 | 检查麦克风权限（Windows 设置 → 隐私 → 麦克风）与默认输入设备 |
| 工具调用总是弹确认框 | 默认「全自动」执行，仅「对外发送 / 账号支付 / 未知工具」类强制确认；想把高危操作也弹窗，把「执行模式」切到「逐次确认」 |
| 看屏幕很慢 | 视觉走独立 HTTP 通道，比语音慢 1~3 秒，属正常 |
